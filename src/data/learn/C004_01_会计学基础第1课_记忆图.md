## ⚡ 速查卡片

| 概念 | 一句话 | 关键点 |
|------|--------|--------|
| 会计 | 以货币为尺度的商业语言 | 综合性 + 敏感性 |
| 资产 | 过去形成·现在控制·未来利益 | 三维时间缺一不可 |
| 控制 | 实质上拥有（利益+风险+支配权） | ≠ 法律所有权 |
| 负债 | 有偿还义务 | 过去交易·现时义务 |
| 所有者权益 | 资产 - 负债 = 剩余 | 无偿还义务 |
| 实质重于形式 | 经济实质优先 | 融资租赁是经典案例 |

> - "准则 + 审计 = 完整的制度保障"
