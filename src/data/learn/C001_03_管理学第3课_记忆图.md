## 一、管理思想演变 · 全景时间线

```mermaid
timeline
    title 西方管理思想演变脉络
    工业革命 : 经验管理思想 : 德鲁克/明茨伯格, 中国:修身→齐家→治国→平天下
    1911年 : 科学管理思想 : 泰勒(作业), 法约尔(职能), 韦伯(官僚组织), 孙武(兵法)
    1920s : 行为管理思想 : 霍桑实验, 马斯洛需求层次, X/Y理论
    二战 : 定量管理思想 : 运筹学→管理科学, 作业管理, 信息系统
    1970s : 权变管理思想 : 系统/权变/过程理论, If X then Y only in Z
    当代 : 创新管理思想 : VUCA时代, 乱中取胜
```

## 二、五大思想 · 一张图对比

```mermaid
mindmap
  root((管理思想))
    经验管理
      核心：管理者素质与经验
      代表：德鲁克·明茨伯格
      中国：修身齐家治国平天下
      局限：难以传授推广
    科学管理
      核心：科学方法代替经验
      泰勒：作业层面提效率
      法约尔：管理五职能+14原则
      韦伯：官僚组织6原则
      贡献：管理走向专业化职业化
    行为管理
      核心：人是"社会人"
      起源：霍桑实验
      发现：非正式组织力量
      发展：需求层次·X/Y理论
      贡献：改变了管理的思考方式
    定量管理
      核心：管理在于"度"的把握
      起源：二战运筹学
      方法：数学·统计·模型
      方向：Management by Data
    权变管理
      核心：没有普遍适用的最佳方法
      公式：If X then Y only in Z
      本质：实事求是·具体分析
      分支：系统·权变·过程
```
