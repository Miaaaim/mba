## 一、企业生产理论全景

```mermaid
mindmap
  root((企业生产理论))
    企业=生产函数
      投入→产出
      黑箱过程→管理学
    短期分析
      至少一种要素固定
      TP·AP·MP三曲线
        MP先升后降_倒U型
        MP=AP时AP最大
      边际收益递减规律
        追加一种要素→MP最终必递减
        知识经济特例_边际递增
      合理投入区间_MP递减阶段
    长期分析
      所有要素可变
      规模收益
        递增_产量增幅>投入增幅
        不变_等比例
        递减_产量增幅<投入增幅
      柯布-道格拉斯函数
    利润最大化
      MR=MC时利润最大
    成本分析
      短期成本_固定+变动
      长期成本_全部可变
```

## 五、利润最大化核心公式

```mermaid
flowchart TD
    PROFIT["💰 利润最大化条件"]
    PROFIT --> MR["MR 边际收益<br/>多卖一单位增加的收入"]
    PROFIT --> MC["MC 边际成本<br/>多产一单位增加的成本"]

    MR --> COMPARE{"MR vs MC"}
    COMPARE -->|"MR > MC"| MORE["增产！<br/>多产多赚"]
    COMPARE -->|"MR < MC"| LESS["减产！<br/>多产多亏"]
    COMPARE -->|"MR = MC"| OPT["✅ 最优产量<br/>利润最大化"]

    MORE --> COMPARE
    LESS --> COMPARE

    style PROFIT fill:#6c5ce7,color:#fff,stroke-width:3px
```

## ⚡ 速查卡片

| 分析维度 | 核心概念 | 一句话口诀 |
|----------|----------|-----------|
| 短期生产 | 边际收益递减 | 追加必有极限 |
| 长期生产 | 规模收益 | 翻倍投入看产出增幅 |

| 市场结构 | 竞争→垄断光谱 | 企业越多越竞争，越少越垄断 |
| 成本分类 | 固定 vs 变动 | 短期有固定，长期全变动 |
